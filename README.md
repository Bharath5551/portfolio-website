# Portfolio

My personal site: who I am, the projects I've built, my internship work and certificates, and how to reach me.

**Live:** https://bharathmportfolio.vercel.app

## Tech

Hand-written HTML, CSS and JavaScript. No framework and no build step. Hosted on Vercel.

## Run it locally

Open `index.html` in a browser, or:

```bash
npx serve .
```
